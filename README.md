# DiagnosticsScript
Eastrica OS Heal - мощный PowerShell-скрипт (41 этап) для глубокой диагностики, восстановления и оптимизации Windows. Он автоматически чинит ядро (DISM/SFC), сбрасывает службы, сеть и права к заводским настройкам, анализирует BSOD и диски (S.M.A.R.T.), восстанавливает WMI и очищает кэши. Возвращает ОС в идеальное состояние.
